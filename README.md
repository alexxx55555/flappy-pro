# Flappy Pro — installable version

Upload this whole folder to any static host that serves over HTTPS (GitHub Pages, Netlify, Cloudflare Pages, Vercel).
Open the site once while online, then use your browser's "Install" or "Add to Home Screen" option. After that it runs offline.

The shared leaderboard and cloud save only work in the claude.ai-hosted version; here, progress is saved on the device.
